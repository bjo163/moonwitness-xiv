# Evidence K3-004 — typed reviewed relation graph projection

## Status

- Status: implementation complete locally; hosted CI, human review, and protected promotion remain delivery gates.
- Date: 2026-10-16 (Asia/Jakarta).
- Dependencies: K3-002 exact evidence selectors and K3-003 human-reviewed identity decisions.
- Scope: versioned research relation contract, graph integrity validation, and a bounded readable adjacency projection in `@moonwitness/research`.

## Result

- Added `ontology/core/research-relation.schema.json` (schema version 1) and typed relation/graph APIs in `packages/research/src/relation.ts`.
- The allowlisted vocabulary distinguishes structural predicates (`edition_of`, `witness_of`, `member_of_canon`, `derived_from`) from contestable predicates (`related_to`, `textually_parallels`, `possibly_corresponds_to`) and human-decided `explicit_identity_equivalence`.
- Relations carry lifecycle/revision, visibility, predicate, endpoints, scope, supporting and counterevidence, alternatives, epistemic status, and review provenance. Accepted relations require current-revision review, supporting evidence, a reviewer, and a decision record.
- Graph validation checks canonical and unique record IDs, valid `kind`/identity-class pairings, endpoint/predicate types, evidence/scope/reviewer/decision references, monotonic visibility across referenced records, identity decision provenance, and DAG structure for active accepted `derived_from` edges. Cycles in contestable predicates are permitted.
- Identity equivalence requires a matching accepted, valid, uncontested K3-003 decision and matching reviewer/review timestamp; rejected or conflicting decisions cannot become edges.
- Adjacency queries are deterministic and bounded. The default exposes `PUBLIC_APPROVED` only; roots, endpoints, scope, evidence (including identity-decision evidence), reviewer, decision, relation and alternative records must be readable before traversal. Hidden roots return the same `not_found` response as missing roots, and the projection omits review actor/decision IDs and source origin metadata.
- Implementation remains a pure package projection. No API route was added because ADR 0004 leaves graph persistence/snapshot sourcing open; serving an API response without an approved canonical snapshot would invent storage and freshness semantics. An API route should follow once K-series storage/release contracts provide that source.
