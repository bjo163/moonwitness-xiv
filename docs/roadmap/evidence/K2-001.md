## Result

- Added a strict versioned recipe format that pins one local source file by relative path and exact SHA-256, with one explicit parser (`json-record-array/v1`). Unsupported parser IDs, extra fields, absolute paths, traversal, and symbolic links fail closed. The adapter contains no network client or dynamic parser loading.
- The parser accepts duplicate-key-safe UTF-8 JSON only, validates every row against the knowledge record schema, rejects duplicate record IDs, sorts records deterministically, and computes the existing RFC 8785 dataset snapshot.
- Added a dry-run report and immutable import output. The complete input is validated before writes; output files are canonical JSON, staged in a sibling directory, and published by rename. Existing release paths cannot be overwritten, and failed checksum/parser/record validation does not publish a partial snapshot.
- Added package documentation, a recipe JSON Schema export, and `scripts/knowledge/ingest.mjs`. Tests use synthetic data only; this does not clear source rights or import historical corpora.
