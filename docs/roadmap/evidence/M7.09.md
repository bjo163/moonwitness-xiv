## Contract

- Release tags must pass the exact source gate described in [M7.07](M7.07.md).
- API and Board candidate images carry `org.opencontainers.image.revision` and `org.opencontainers.image.version` labels. Both are smoke-tested from those exact local tags; `SMOKE_USE_PREBUILT_IMAGES=true` makes Compose use `--no-build`.
- Trivy blocks on unfixed-filtered CRITICAL OS/library findings for each exact candidate before the image artifact is uploaded.
- The verify job saves both images into one tar, records their image IDs and source/version in a manifest, writes SHA-256 checksums for both files, uploads the artifact for 30 days, and records the GitHub artifact ID/digest in the job summary.
- Publish downloads the same-run artifact, verifies its checksums, manifest source/version, both image IDs and labels against `GITHUB_SHA` and the tag, then pushes the loaded images without invoking a build.
- Publish records each version-tagged OCI digest. When a stable `latest` alias is pushed, it requires that alias to resolve to the exact same digest before reporting success.
- Prerelease tags do not update `latest`. Application deployment is not part of the workflow.
