## Result

- Added `putRawArtifact` and `readRawArtifact` for exact binary bytes under `sha256/<first-two-hex>/<full-sha256>` in an existing store directory.
- Writes validate the requested lowercase SHA-256 before deriving a path, verify bytes before storage, stage in the destination directory, and publish with an atomic no-overwrite hard link. Repeating identical content is idempotent. A mismatching digest, corrupt existing object, or unexpected symlink/non-directory path is rejected without replacing stored bytes.
- Reads verify the stored bytes against the requested digest. A failed read does not create missing store paths.
- The store contains bytes only. It provides no rights clearance, source attribution, or publication authorization.
