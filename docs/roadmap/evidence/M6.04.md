## Delivered

- `pnpm docs:generate` builds the required addon packages, regenerates the platform/model/API references, and updates the bounded generated README block. `pnpm readme:generate` delegates to this same command.
- `pnpm docs:check` builds the required source packages, runs generator/README/guide-bundle tests, compares expected references in a temporary directory, checks the README block, then invokes `pnpm docs:links`.
- Check mode never writes tracked reference files. When outputs differ, it exits nonzero and lists every stale, missing, or removed output path in stable order.
- `pnpm docs:links` checks local Markdown links and navigation targets and runs navigation fixtures.
- `pnpm docs:build` runs the complete docs check then creates the ignored `dist/docs/guide.bundle.json` bundle from navigation, generated source fingerprint, and Markdown pages. The bundle builder rejects unsafe paths and absent page content before reading pages.
- The required CI quality lane now runs `pnpm docs:build`, so the documentation bundle is built on hosted validation and on `pnpm verify`.
