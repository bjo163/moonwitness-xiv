# Evidence K3-001 — scoped research assertions

## Status

- Status: complete locally; hosted CI and protected promotion remain delivery gates.
- Date: 2026-10-16 (Asia/Jakarta).
- Dependencies: K1-004 provenance contract and K2-007 authenticated source/passage lookup, both complete locally.
- Scope: a versioned core assertion schema and typed package API for validation and explicit lookup. This milestone does not create a global knowledge graph or automatically promote assertions.

## Result

- Added the Draft 2020-12 JSON Schema at `ontology/core/assertion.schema.json`. It requires claim polarity, non-global scope, context mode/reference, epistemic status, review status, provenance, visibility, lifecycle, timestamps, and content revision.
- Direct quotations and reported speech require an explicit speaker. Scope kinds are limited to passage, speaker, document, work, community, time, or research context; `global` scope is rejected.
- Added the `@moonwitness/research` package with strict TypeScript types, schema-backed runtime validation of untrusted `unknown` values, and an explicit `found`/`missing` lookup union. Missing assertions are never interpreted as negative claims.
- Added synthetic tests for scoped quoted claims, explicit negative polarity, rejected global scope, missing-speaker rejection, and a missing lookup distinct from false.
- Registered package build/typecheck/tests and assertion tests in the root CI unit-test target.
