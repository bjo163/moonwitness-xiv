## Result

- Defines source/edition IDs, locale, references, artifact representation and integrity metadata, rights state/use/scope/evidence, attribution, transformation digests, complaint owner, and publication mode.
- Source-byte publication requires `permitted` scoped rights including full redistribution, checksum and byte length, attribution, and complaint-process owner. Unknown rights remain metadata-only.
- Manifest objects reject undeclared/raw byte content; source bytes are referred to by digest rather than embedded or rewritten by this contract.
- This schema does not issue rights decisions, import bytes, or prove that a future ingestion pipeline preserves bytes. Runtime ingestion and snapshot integrity remain downstream acceptance work.
