- Status: implementation and local acceptance are complete on `dev`; exact-SHA hosted verification and protected promotion remain delivery gates.
- Date: 2026-10-15 (Asia/Jakarta)
- Dependency: K1-001 core record envelope is locally accepted.
- Scope: `packages/knowledge/`; synthetic identifiers only. No source corpus, rights assertion, personal data, persistence, import or publication behavior was added.
- Contract: persistent IDs use `mw:<kind-token>:<canonical-token>`, with kind tokens derived as lowercase kebab-case from the 19 kernel kinds. Token segments are lowercase ASCII alphanumeric groups separated by `.`, `_`, or `-`; colon separates hierarchical segments. IDs are limited to 500 characters.
- Resolution is exact and case-sensitive. It accepts a registered canonical ID or an explicit `(namespace, value)` alias. Alias collisions return sorted conflict candidates, duplicate canonical registry IDs are surfaced, dangling aliases are explicit, and malformed registries fail closed. Titles and similarity do not resolve records.
