## Rebuild procedure

Build the local packages, then run the CLI against an existing local source root and a new empty output directory:

```sh
pnpm --filter @moonwitness/knowledge build
pnpm --filter @moonwitness/corpus build
node scripts/knowledge/rebuild.mjs --root <local-source-root> --output <empty-output-directory>
```

`scripts/knowledge/rebuild.mjs` reads the two checked-in local indexes and calls dedicated corpus snapshot readers. Each reader returns the exact source-manifest bytes validated with the passage, along with the verified passage, so the CLI hashes and copies the same manifest that authorized the read. The readers validate index shape, source manifest structure, source-specific permitted uses, and source byte SHA-256/length before returning bytes. The CLI materializes byte-identical indexes and source manifests plus the verified content-addressed source bytes into a clean output directory. `source-reconstruction.json` records each identity and locator, source and manifest digests, byte length, rights state/allowed uses, imported count, and every per-source import error. Any source import error is included in the report and causes a nonzero exit status; it is not swallowed.
