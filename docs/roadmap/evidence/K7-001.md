## Result

- Added `@moonwitness/local-ai` with `AI_MODE=disabled` as the default. Disabled generation returns a typed result without calling fetch or attempting inference.
- `AI_MODE=local` requires an explicit HTTP URL on `localhost`, `127.0.0.1`, or `::1`; it rejects remote/private-network hosts, credentials, query/fragment, unsupported modes, and invalid timeout values.
- The runtime uses a bounded timeout, rejects redirects, limits prompt/response sizes, validates response shape, and returns typed provider failure states. There is no remote fallback, retry, persistence, or logging of prompt/response content.
- The API validates this configuration during startup and decorates Fastify with the runtime. No user-facing route or automatic workflow invokes it; generated text remains untrusted and cannot mutate canonical records.
