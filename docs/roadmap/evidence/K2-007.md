## Result

- Added bearer-authenticated API routes for source citation metadata and exact passage text. Unknown source, edition, or locator returns 404; unavailable or invalid local source data fails closed. OpenAPI documents response variants and 401/404/503 errors.
- Added typed SDK methods and discriminated response types for the Tanzil Q7:46 and WEBP Genesis 1:1 samples. The API only returns passages after the corpus readers validate source-specific `quote_excerpt` rights, exact byte length, and SHA-256.
- Added the offline textual-witness reader with a separate expression/edition/locator identity, safe relative-path and symlink checks, strict UTF-8 decoding, and hash/manifest validation.
- The production API image now copies the pinned `corpus/` directory to `/app/corpus` and sets `MOONWITNESS_CORPUS_ROOT`. The authenticated container smoke path logs in using its synthetic CI credential and exercises both source and both passage routes. No service credential or source text is printed into diagnostics.
- Regenerated the API, model, and platform reference pages from source.
