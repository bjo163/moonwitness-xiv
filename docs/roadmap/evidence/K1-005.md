## Result

- Recursively validates one JSON knowledge record per file in `records/`, optional exact alias mappings in `aliases.json`, source artifact manifests in `source-artifacts/`, and an optional `provenance.json` graph.
- Checks each record envelope and canonical ID/kind pair, duplicate IDs, alias resolution/conflicts, source manifest rights structure and edition references, provenance schema and local record references, and record derivation activity/input references.
- Rejects symbolic links in dataset directories and root manifests. External source URIs are syntax-checked only and never fetched.
- Emits deterministic text or JSON diagnostics and exits `1` for invalid data, `2` for usage/runtime setup errors, and `0` for valid data. It has no API, model, or network client and loads the locally built knowledge package.
- A passing result establishes structural consistency only; it does not verify source-rights claims, establish consent, authorize publication, or prove source bytes match their recorded hashes.
