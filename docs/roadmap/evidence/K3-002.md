# Evidence K3-002 — exact research evidence selectors

## Status

- Status: complete locally; hosted CI and protected promotion remain delivery gates.
- Date: 2026-10-16 (Asia/Jakarta).
- Dependencies: K2-007 local source lookup and K3-001 scoped assertion records.
- Scope: exact, allowlisted references to the repository's currently indexed Tanzil Q7:46 and WEBP Genesis 1:1 passages. This does not claim other passages or editions are available.

## Result

- Added a versioned evidence selector schema and strict research package contract. Selectors bind source, optional expression, edition, locator, exact SHA-256, optional Unicode-scalar range, optional quote, assertion ID, and supporting/counterevidence direction.
- Resolution loads only the exact local corpus passages and checks identity, digest, selected range, and quote. It never fetches remote content and does not infer that evidence supports a claim merely because it is linked.
- Added authenticated `POST /api/research/evidence/resolve` with documented request/response and error schemas. Invalid selectors return 400, unavailable local passage 404, hash/identity/quote conflict 409, and unavailable local source 503.
- Added unit and route tests for both passage sources, counterevidence direction, mismatched hashes, dangling locators, schema references, and authenticated OpenAPI contract.
- Registered research build, typecheck, and tests in workspace CI; API package includes the new workspace dependency.
