# K4-001: Deterministic text segmentation

## Delivered

- Added `segmentText` to `@moonwitness/research`, with exported `TextSegment` and `TextSegmentKind` types.
- The scanner returns lexical word, number, punctuation, symbol, and whitespace spans over the exact input string. Each span carries half-open UTF-8 byte offsets and Unicode-scalar offsets, original text, language, and script metadata.
- Combining marks following a base remain attached to the preceding word. A leading combining mark is kept in its own span. Optional NFC/NFKC output is an explicitly requested derivative; original text and offsets remain unchanged.
- The scanner does not infer lemmas, morphology, or token meaning. It is deterministic and fails closed on unpaired UTF-16 surrogates and unsupported Unicode scripts.
- Script labels use an explicit supported-script table (Arabic, Hebrew, Latin, Greek, Cyrillic, Devanagari, Han, Hiragana, Katakana, Thai), `Zyyy` for Common and `Zinh` only for Inherited. Other scripts and script-specific unsupported marks/symbols are rejected. Unicode Script properties allow Han extension characters, including CJK Extension G, to be recognized as `Hani`.
