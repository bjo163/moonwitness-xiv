# Universal Correlation Matrix — V1 Candidate Research Edition

**Scope:** 4 distinct lenses — Narrative, Terminology, Research, and System/Ownership. **Status:** PROPOSED / NONCANONICAL. No operational graph migration, new schema, Board feature, production data write or human approval is claimed.

This matrix is a **reviewable analytic index**. Candidate relationship labels below are **descriptive proposal names**, not registered ontology predicates. The owner of `ontology/` and the K-series tasks must map them to existing versioned predicates before any structured canonical record is created.

## Edge semantics

- **Source-described**: a publicly inspectable lore/review reference contains the general relationship, but precise commit/span still needs review.
- **Candidate**: plausible relationship or user-reported creative link; not approved.
- **Editorial analogy / speculative theme**: cross-story interpretation by researchers; never treated as intended authorial or metaphysical equivalence.
- **UNRESOLVED/CONFLICT**: preserved as an explicit review state; do not encode as `sameAs`.
- **Ownership**: a policy statement, not a theological claim.

## Production promotion checklist (per edge)

Every proposed edge must be reconciled to approved contract fields **without claiming these exact keys already exist**:

1. Stable internal left/right record identifiers, type, universe, named owner and relationship vocabulary version.
2. Evidence source ID(s), exact artifact revision, digest and passage/time/page locator where independently available.
3. Epistemic class: author-primary manuscript, text witness, user-reported personal experience, fictional canon, derivative art, research interpretation, or AI editorial synthesis.
4. Event time versus observation/recording time versus artifact publication time; precision and timezone where relevant, otherwise `UNKNOWN`.
5. Rights/privacy/consent and original-vs-derivative distinction; private source bodies must never leak into the public review.
6. Review state and conflicts: `candidate`, `needs_source`, `conflict`, `rejected`, or reviewed acceptance **only via the approved XIV workflow**.
7. Reviewer ID, decision evidence, correction/retraction path, source-rights revocation impact, and immutable revision.
8. Negative test: similar labels **must not** create an identity equivalence unless an actual approved [identity decision](../../../ontology/mappings/identity-decision.schema.json) exists.

## Negative controls

- An identical numeric label (99, 33, 10, 1·6·3) cannot become an equivalence rule.
- An image generated from a textual brief is not the original manuscript.
- A Quran reference is not proof of a user-specific message or a completed supernatural event.
- A story character inspired by an angel/prophet is not an identification with that being.
- A fictional timeline does not overwrite source timestamps; the Tick-Tock event is not MOONRIDLEY morning framing.
- No embedded numeric confidence score establishes a doctrinal proposition or historical fact.
- A published Markdown draft in public Git does not change operational canon in PostgreSQL.
