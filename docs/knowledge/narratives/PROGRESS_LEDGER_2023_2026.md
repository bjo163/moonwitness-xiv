## A. How to interpret a progress row

- **USER-REPORTED** — fact or choice recorded in a conversation; source artifact or implementation may be absent.
- **REPOSITORY-DOCUMENTED** — code, issue, registry, asset inventory or policy is observable in a named repo; does not guarantee feature works.
- **IMPLEMENTED/TESTED LOCALLY** — source and specified local test evidence exist; deployment/publication requires separate proof.
- **HOSTED-VERIFIED-SHA** — GitHub Actions status explicitly tied to stated commit, not to latest branch in perpetuity.
- **DRAFT / EDITORIAL** — intentionally a proposal, reconstruction, creative prompt, or design artifact.
- **BLOCKED/UNKNOWN** — upstream evidence or owner decision absent. Preserve it rather than invent completion.
